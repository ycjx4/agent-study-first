# agent-study-first

这是一个用于测试和优化 2σ 掌握学习 skill 的实验仓库。

实验以《思考，快与慢》的个人学习过程为样本，记录学习文档、用户作答、理解评估、进度状态，以及我们对教学门槛的调整。重点不是整理原书内容，而是观察 AI 导师能否根据真实回答决定“继续推进”还是“换一种方式补救”。

## 当前实验问题

旧流程在第 5 课后发现两个统计概念仍不稳固：

- 把“小样本容易产生极端比例”理解为“低概率事件连续发生的概率更低”。
- 在缺少总体就业数据时，直接断言某专业就业困难的“基础比率很小”。

旧版 `06.md` 虽然在开头纠正了这两个问题，却继续推进到了“过度自信”。这暴露出一个核心缺陷：反馈存在，但没有真正执行掌握门槛。

修改后的 skill 增加了：

- 回答过短时的聊天追问。
- 掌握不足时禁止推进的硬门槛。
- 使用不同入口重新教学的 remediation 文档。
- 三篇内复测模糊概念的 spaced retrieval。
- 记录理解水平、误解与教学方式的 Learning Journal。


## 测试历程

1. 将 EPUB 粗转换为 Markdown，验证其可作为学习资料来源。
2. 根据用户偏好建立学习路线：中文、理工学生、中等篇幅、系统掌握与实践应用。
3. 完成第 1 至第 5 课的学习与问答。
4. 旧流程生成“推进版” `06.md`，暴露掌握门槛不够严格的问题。
5. 修改 2sigma skill，加入追问、补救、复测和学习日志机制。
6. 生成补救测试设计，准备把 `06.md` 重生成为统计直觉补救课。

当前提交刻意保留旧版 `06.md`，作为重生成前的基线。下一次提交将展示严格门槛下的新版 `06.md` 和进度变化。

## 资料说明

本仓库不包含《思考，快与慢》的 EPUB、PDF、MOBI 或转换后的原书正文。`examples/` 只保存实验过程中生成的学习材料和用户回答。
