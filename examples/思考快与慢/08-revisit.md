# Revisit: 人工判断怎样证明自己比规则更好

## What wasn't quite clicking

你已经知道人工调整要减少主观性，但还没有建立验证闭环：**改判时保留两份预测，结果出现后再比较哪一份更准**。

## Let's try a different approach

先不用招生，因为被拒学生后来的大学表现很难观察。我们换成一个结果能被所有人共同检验的场景。

某学校想预测100名学生能否通过三个月后的统一资格考试。固定规则根据平时成绩和模拟考试，给每人一个“通过/不通过”预测。老师可以根据规则未覆盖的新证据提出改判。

学生小林的记录如下：

| 需要保存的内容 | 具体记录 |
|---|---|
| 规则原预测 | 不通过 |
| 老师是否改判 | 改为通过 |
| 改判证据 | 最近完成同难度项目，且三次补测持续上升 |
| 老师的预测 | 正式考试分数不低于70分 |
| 记录时间 | 考试结果公布前 |
| 后来的真实结果 | 78分，通过 |

这里最重要的动作是：**老师改判后，不能删除规则原预测**。如果删掉，就只剩最后决定，无法知道人工判断有没有增加价值。

三个月后，所有学生都参加同一场考试。现在可以对每个改判案例比较：

- 固定规则预测对了吗？
- 老师改判对了吗？
- 老师写下的证据在类似案例中是否反复有效？

假设一年内共有30次人工改判。规则在其中预测对了20次，老师预测对了23次。这个结果提示人工调整可能有价值，但还不能只凭一次成功案例下结论。需要继续积累案例，并检查老师是否只在某类学生上更准确。

如果“近期补测持续上升”多次证明有预测价值，就不应永远依赖某位老师的感觉。下一步是把它加入固定规则，让系统整体学习。

## 四步验证闭环

| 步骤 | 要做什么 | 防止什么问题 |
|---|---|---|
| 1. 保留基线 | 保存固定规则的原预测 | 防止改判后失去比较对象 |
| 2. 记录改判 | 写明新证据、预测结果和时间 | 防止用“感觉”代替可检查理由 |
| 3. 等待反馈 | 用预先确定的真实结果检验 | 防止事后更换成功标准 |
| 4. 批量比较 | 比较多次改判与规则的准确率 | 防止把一次走运当成专家能力 |

你可以把它理解成一场比赛。规则和专家在结果公布前各自交一张密封答卷，结果出来后统一对答案。专家不能看完答案再改自己的预测，也不能只展示猜中的几次。

这正好连接上一课：可靠专家需要高质量反馈。**记录两份预测，再与真实结果比较，就是人为建立反馈。**如果不记录，经验只会留下模糊印象；如果持续记录，专家才能知道自己的直觉在哪类任务上确实有效。
